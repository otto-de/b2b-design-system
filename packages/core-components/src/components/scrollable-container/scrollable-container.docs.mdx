# Scrollable Container

This component is a helper container that encapsulates the classes to make the content scrollable both horizontally
and vertically. The scroll will only appear when the content is bigger than the container.

This container sets the `white-space` property as `nowrap` via its shadow DOM, so direct children will inherit
this value. To enable vertical scrolling, wrap the content in a native element (e.g. a `<div>`) and set
`white-space: normal` on that wrapper — this reliably overrides the inherited value regardless of shadow DOM
cascade rules.

```html
<b2b-scrollable-container style="width: 400px; height: 50px">
  <!-- Any content -->
</b2b-scrollable-container>
```
